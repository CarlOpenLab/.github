# Carl OpenLab — `.github`

This repository holds organization-wide configuration for [Carl OpenLab](https://github.com/CarlOpenLab):

- **`profile/README.md`** — the introduction rendered on the [organization profile page](https://github.com/CarlOpenLab).
- **Everything at the repository root** — default community health files, inherited by every repository in the organization that does not define its own:
  - [`SECURITY.md`](./SECURITY.md) — how to report a vulnerability privately
  - [`CONTRIBUTING.md`](./CONTRIBUTING.md) — how to file an issue or open a pull request
  - [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md)
  - [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md)
  - [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE) — issue forms and the issue chooser config

Nothing here is installed or published; it is consumed by GitHub itself. Changes take effect across the organization as soon as they land on `main`.
